# NCViewer UI 设计说明

## 方向

本版采用 **“纸白科研编辑部”** 风格：像一张高质量科研工作台和期刊排版的结合。主背景是暖纸白，正文是墨黑，朱砂红用于当前选择和关键动作，苔藓绿只作为数据状态辅助色。它与之前的“深蓝底 + 冰青 accent + 大圆角扁平卡片”明确不同：没有深色满屏底、没有霓虹青、没有统一大圆角，而是通过纸张层级、细分隔线、标题下划线和克制的色彩建立秩序。

## 一句话定位

**为气象科研人员准备的纸白色数据工作台：读数据像读一页清晰的实验记录。**

|---|---|---|
| paper-0 | `#F4F1EA` | 应用主背景 |
| paper-1 | `#FBFAF7` | 面板、树、输入区 |
| paper-2 | `#E9E3D8` | 菜单栏、工具栏、表头 |
| ink | `#24211D` | 主文字 |
| muted | `#756F65` | 辅助文字 |
| vermilion | `#B84A3A` | 主强调、选中、滑块 |

| 间距 | 4 / 8 / 12 / 16px | 控件内外节奏 |

## 关键差异化设计点

1. **纸白底 + 朱砂红**：暖色纸张让白底图形区自然衔接，朱砂红比冰青更像科研标注，视觉识别更强。
2. **连续选中带**：数据树选中项采用整行浅朱砂底和左侧实色标尺，三级层级中不会出现断裂的胶囊块。
3. **编辑部标题语法**：section title 使用粗体墨字与 2px 朱砂下划线，GroupBox 标题贴在边框线上，形成期刊式分栏。
4. **传统桌面密度**：输入框和表格保持 2px 边角、明确边框与表头，信息密度高但不老旧；Matplotlib 工具栏改为纸白小卡片，与白色科研图形区一致。
5. **层级靠材质而非阴影**：主背景、面板、表头使用三档暖灰纸色和细线区分，避免常见的深色玻璃拟态和大面积渐变。
